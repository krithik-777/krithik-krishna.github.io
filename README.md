Welcome to the repository for my professional portfolio. I am a **Digital Design Engineer** at **Whirlybird Electronics**, specializing in FPGA architectures and RTL automation. This site serves as a central hub for my technical projects, engineering blog, and professional journey.

## 🚀 About This Project
This portfolio is built using **Jekyll** with a customized **al-folio** theme. It is optimized for high-performance rendering and clean technical documentation, reflecting the precision required in hardware engineering.

### Key Sections:
* **[About Me](https://krithik-krishna.github.io/about/):** Professional background in RTL, Verilog, and Python automation.
* **[Blog](https://krithik-krishna.github.io/blog/):** Insights into life as an engineer, travel journeys (including the 1AC move to Vasai), and technical musings.
* **[Projects](https://krithik-krishna.github.io/projects/):** Showcasing hardware tools like the Excel-to-Verilog UART generator.
